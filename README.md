
# Exercícios de Linguagem de Programação: Java

(˶ᵔ ᵕ ᵔ˶) ♡

Este repositório reúne exercícios e atividades desenvolvidos em 2025, durante o terceiro período do curso de **Sistemas de Informação**, na disciplina de Linguagem de Programação.

Os exercícios vão desde conceitos básicos de lógica de programação até aplicações envolvendo classes, objetos, herança e polimorfismo. Este repositório também serve como registro de uma das etapas da minha trajetória acadêmica. (˶˃ ᵕ ˂˶)

## 📚 Conteúdo

### Listas de exercícios

| Pasta | Conteúdo |
|---|---|
| `Lista 01 - Fundamentos` | Exercícios de lógica de programação, cálculos matemáticos, médias, ajustes de saldo, cálculo de IPI, antecessor e sucessor, entre outros. |
| `Lista 02 - Classes e Objetos` | Exercícios envolvendo playlist musical, gerenciamento de notas de alunos, organização de tarefas e cadastro de medicamentos. |
| `Lista 03 - Herança` | Modelagem de veículos, contas bancárias, pessoas e cargos profissionais, personagens de jogos, qualidade do ar, alimentos orgânicos e placas solares. |
| `Lista 04 - Polimorfismo` | Sistemas para representar animais de um zoológico e calcular pagamentos de empregados com diferentes formas de remuneração. |

### Atividades práticas

| Pasta | Conteúdo |
|---|---|
| `Atividade - Aprovação de empréstimo` | Análise de solicitações de empréstimo com base em critérios de aprovação. |
| `Atividade - Consumo de água e empréstimo` | Exercícios envolvendo análise de consumo de água e processamento de solicitações de empréstimo. |
| `Atividade - Sistema bancário` | Modelagem de clientes e contas bancárias, incluindo contas correntes, contas poupança e operações relacionadas a impostos. |

## 🛠️ Tecnologias e conceitos

- Java
- Lógica de programação
- Programação orientada a objetos
- Classes, objetos, herança e polimorfismo

## ♡ Sobre o repositório

Os códigos foram preservados conforme as entregas originais, mantendo as soluções desenvolvidas durante o terceiro período da graduação.

Este repositório é um registro do meu aprendizado e de onde minha jornada com Java começou. ◝(ᵔᗜᵔ)◜

# Java Programming Exercises

(˶ᵔ ᵕ ᵔ˶) ♡

This repository contains exercises and assignments completed in 2025, during the third semester of my **Information Systems** degree, as part of the Programming Languages course.

The exercises range from basic programming logic to applications involving classes, objects, inheritance, and polymorphism. This repository also documents one stage of my academic journey. (˶˃ ᵕ ˂˶)

## 📚 Contents

### Exercise lists

| Folder | Contents |
|---|---|
| `Lista 01 - Fundamentos` | Programming logic, mathematical calculations, averages, balance adjustments, IPI calculations, predecessor and successor numbers, and other exercises. |
| `Lista 02 - Classes e Objetos` | Exercises involving a music playlist, student grade management, task organization, and medication registration. |
| `Lista 03 - Herança` | Modeling vehicles, bank accounts, people and professional roles, game characters, air quality, organic food, and solar panels. |
| `Lista 04 - Polimorfismo` | Systems for representing zoo animals and calculating employee payments using different compensation methods. |

### Practical assignments

| Folder | Contents |
|---|---|
| `Atividade - Aprovação de empréstimo` | Analyzing loan applications based on approval criteria. |

| `Atividade - Sistema bancário` | Modeling customers and bank accounts, including checking and savings accounts and tax-related operations. |
